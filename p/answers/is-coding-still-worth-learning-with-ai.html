Is coding still worth learning now that AI can write it?

This is a fair question and deserves a straight answer rather than reassurance. AI genuinely does write working code, and it is reasonable to ask what is left.

What actually changed

Producing a block of syntactically correct code is no longer the hard part, and pretending otherwise would be dishonest. What has not changed is deciding what to build, judging whether the result is right, and understanding what went wrong when it is not.

You cannot supervise what you don't understand

Someone who cannot read code cannot tell working code from confidently wrong code. As more code is machine-generated, the ability to review it becomes more valuable, not less. That ability is built the same way it always was - by writing code yourself first.

Coding teaches something more general

Breaking a vague problem into precise steps, testing an assumption, isolating a fault - these transfer to almost everything. That was always the strongest argument for teaching kids to code, and it is untouched by AI.

The realistic view of jobs

Nobody should promise your child a specific career from a coding course. What is defensible is that fluency with computation is becoming a baseline literacy across many fields, in roughly the way spreadsheet literacy did a generation ago.

What we'd actually teach differently

Less emphasis on memorising syntax, more on reading code critically and describing problems precisely. Those are the durable skills.
